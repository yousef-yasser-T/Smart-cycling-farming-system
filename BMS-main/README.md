# BMS
# EV Battery Management System

Hardware design of a Battery Management System for Electric Vehicle applications.

## Overview

Designed the BMS schematic and PCB using KiCad, with manufacturing-ready Gerber files.

## Key Features

- Cell voltage monitoring
- Battery protection
- Temperature monitoring
- Current monitoring
- Cell balancing
- BMS control and monitoring

## Design

- Schematic: KiCad
- PCB Layout: KiCad
- Manufacturing: Gerber files
- BMS IC: TI BQ76920
